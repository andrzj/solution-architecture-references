Security Architecture

Compliance Frameworks

SOC 2, ISO 27001, PCI DSS, HIPAA — compliance controls and implementation patterns.

⏱ 10 min read

What it is

Example: SOC 2 Type II requires demonstrating access reviews, change management, and monitoring over a 6–12 month audit period—not a one-time checklist.

Why it exists

Customers and regulators require independent assurance. Mapping architecture decisions to control frameworks prevents ad-hoc audits and duplicative work across sales, legal, and engineering.

When to use

  • Selling to enterprise or handling regulated data.
  • Processing payments (PCI) or health records (HIPAA).
  • Building a trust program for global customers (ISO 27001).

When not to use

  • Treating the framework as exhaustive security — it is a baseline.
  • Certifying before foundational controls (MFA, logging) exist.

Typical architecture

Pros and cons

Pros

  • Shared language with customers.
  • Prioritizes durable controls.
  • Drives logging and access hygiene.
  • Supports market expansion.

Cons

  • Documentation burden.
  • Checkbox risk without engineering buy-in.
  • Overlapping frameworks duplicate work.
  • Audit cost and calendar constraints.

Implementation notes

Maintain a live control matrix mapped to infrastructure (IaC policies, SIEM use cases). Automate evidence collection where possible.

Run internal mock audits quarterly; track exceptions with expiry and risk acceptance sign-off.

Common failure modes

  • Manual screenshots instead of continuous control monitoring.
  • Shadow IT outside audit scope.
  • Stale access reviews.
  • Unmapped custom controls after architecture changes.

Decision checklist

  • Control matrix owned and versioned?
  • MFA and logging meet baseline?
  • Change management linked to tickets?
  • Vulnerability SLAs defined?
  • Vendor risk process for subprocessors?
  • Incident response tested annually?

Example use cases

  • SaaS SOC 2: Drata/Vanta continuous monitoring plus Okta access reviews.
  • Fintech PCI: Segmented CDE with quarterly ASV scans.
  • Healthtech: HIPAA BAA chain with encrypted backups.
